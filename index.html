Del servidor a la plataforma

Una misma página HTML permite comparar tres formas de publicación: un servidor IIS en una máquina virtual, un sitio estático en Azure Storage y una aplicación web conectada a un repositorio GitHub.

01

Infraestructura IaaS

La máquina virtual aloja IIS. El administrador configura el sistema operativo, el sitio y las reglas de red necesarias.

02

Almacenamiento estático

Azure Storage distribuye archivos HTML, CSS y JavaScript mediante un endpoint web. Esta página funciona sin procesos de servidor.

03

Plataforma PaaS

App Service administra la plataforma de ejecución. Un repositorio permite conservar versiones y organizar las actualizaciones del sitio.

Redes y protección

Las redes virtuales y subredes organizan el direccionamiento privado. Los grupos de seguridad filtran conexiones. Las copias de seguridad y la redundancia protegen la información frente a fallos.
